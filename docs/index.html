为什么要留下痕迹

河南驻马店，一位叫袁淑芳的老中医，97岁走的。她16岁嫁人时一个字不识，借着月光跟丈夫学认字、学医术，行医八十年

临终前她跟家人说了一句话：「我这一百个方子，是这辈子一个一个人试出来的，不能带进土里」

家人把一百个药方刻在了她的墓碑上，连用量都写得清清楚楚——打破了「传方不传量」的老规矩。她孙子说：「人家祖传的东西都藏着，传男不传女，她这还公开呢」

墓碑立了十九年，两三千人从全国各地赶来抄方。有人坐长途火车，有人在碑前蹲一整天。漯河一个八十岁的老中医，凌晨五点起床转三趟车来抄，激动得一晚上没睡着。还有一个德国医生，开了两小时车赶来，他说他看重的是老人八十年的经验大成

一个人一辈子活过、爱过、撑过来的那些年头，总有些东西值得留下来。不一定是药方，不一定是惊天动地的事——可能只是某一年你说的一句话，做的一件事，或者一个再也回不去的瞬间

这世界，你来过。别让它只是来过。
